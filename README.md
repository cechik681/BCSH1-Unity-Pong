# BCSH1-Unity-Pong
BCSH1 Unity <ins>Pong (2D)</ins>

- sledované herní objekty: pálka hráče 1, pálka hráče 2, míček, ohraničující stěny a ukazatel skóre
- ukládání času a skóre poslední hry do souboru
- umožňuje dvěma uživatelům hrát proti sobě na jedné klávesnici
- obsahuje 3 různé úrovně
- plynule animovaný míček a pohyb pálek
- průběžné počítání skóre a následné vyhodnocení vítěze/poraženého
